## 2. 共享数据合同

`FeatureType::Hole` 追加为 14，已有枚举数值保持。`CHole` 的字段如下。

| 字段 | 合同 |
|---|---|
| `supportRef` | 已存在的基准平面或平面面引用，复用 CRef* 解析及父特征映射 |
| `locations[].entryPoint` | 实际入口平面上的全局点；首版恰好一个 |
| `locations[].positionRef` | 能保留的定位依赖；目标无法表达时显式失败 |
| `direction` | 从入口指向材料内部的全局单位向量 |
| `diameter` | 主孔圆柱段直径 |
| `extent` | VALUE 定深或 THROUGH_ALL 原生贯穿 |
| `bottom` | 盲孔 Flat / Conical；贯穿为非活动参数 |
| `depthReference` | 盲孔 Shoulder / Tip；平底规范为 Shoulder |
| `drillPointAngle` | 钻尖完整夹角，弧度；仅锥底盲孔活动 |
| `counterbore` | 可选大径、从实际入口量起的沉孔深度 |
| `countersink` | 可选大径、沉头完整夹角，弧度；与 counterbore 互斥 |

长度全部使用模型单位。单位转换同时处理孔径、深度、入口点、支撑引用和入口
大径；弧度和单位方向不缩放。复用既有引用访问集合，避免共享指针被重复缩放。

## 3. 深度算法与有效性

公共纯函数 `ResolveHoleGeometry` 不依赖 CAD SDK，三侧写计划均复用它。
主孔径为 d，钻尖完整夹角为 theta：

```text
h_tip      = d / (2 * tan(theta / 2))
L_tip      = L_shoulder + h_tip
L_shoulder = L_tip - h_tip
```

沉头大径 D，完整夹角 alpha：

```text
h_csink = (D - d) / (2 * tan(alpha / 2))
```

所有轴向长度从实际入口平面量起，不能把主孔深度改为从沉孔底面起算。
有效主圆柱长度为 `L_shoulder - entryHeight`；普通直孔 entryHeight=0，沉孔
entryHeight=counterbore.depth，沉头 entryHeight=h_csink。

例如 Ø10、118°、钻肩 20 mm：钻尖高 3.004303095137802 mm，到尖深度
23.004303095137802 mm。Ø6.6/Ø12.6、90° 沉头高 3 mm；82° 应重新计算，
不能把 90° 的高度直接套用。

统一 Validator 拒绝非有限或非正活动尺寸、无效夹角、非单位轴、多孔位、
不垂直/不在支撑平面的入口、互斥入口同时活动、入口耗尽主圆柱、未知锥底深度
基准，以及不存在或顺序在后的引用。Extent 的偏置、翻转和实体终止超出首版。

贯穿保持 THROUGH_ALL，盲深/孔底/钻尖/深度基准不参加几何计算。保存时在副本
中清除非活动 NaN/历史值，避免 cereal JSON/XML 写坏；不修改调用者的内存模型。
平底保存时规范为 Shoulder，并清除不活动的钻尖角。

### 孔位、历史阶段与后续圆角引用

孔位始终是孔轴与实际入口平面的交点。平面的参数法向须结合原生曲面方向，
不能直接把 du×dv 当实体外法向；原始定位点不在入口上时，须沿孔轴投影。
固定坐标草图则保留真实原点和X/Y/Z轴，空业务平面引用不等于标准XY。
在SW中按实际位置草图逆变换计算局部坐标，创建后确认真实原生点；必要时用
原生点设置接口精确定位，再执行所有几何后检。SetSelectionPoint2成功仍不足以
证明斜面孔位正确。

孔的固有圆柱不能从已被后续圆角修剪的最终实体直接测量。Reader须在孔阶段
获取孔的完整参数/形体，并恢复后续特征后读取完整模型；圆角引用集合则在圆角
之前读取。恢复是否成功另外通过完整STEP验证，不允许停留在回退状态。

源与目标内核可能把同一圆分成不同边，闭合圆的参数缝也可不同。CRefEdge继续
保存实际原生起点、终点和参数中点，不伪造统一的缝。对父特征明确为Hole的
等半径圆角引用，比较器按父孔的明确轴与半径，结合实际点推导临时圆支持，
先检查等径、同轴、点共面，再比较圆弧覆盖并集。一个完整圆与两个真实半圆
可等价；单个半圆、重复/重叠弧、错误半径/偏轴或缺少父孔证据仍失败。
推导只用于Constant圆角引用，VariableRadius仍保留原参数缝/站位检查。
此算法不增加协议字段；6项新增红绿测试覆盖这些边界。

## 4. 原生创建配方与分层

### 4.1 SolidWorks 2025

- 读取注册 `SketchHole`、`HoleWzd`，根据孔型读取活动属性；Advanced Hole
  明确拒绝，避免因缺少注册而静默漏掉孔。
- 普通平底盲孔和普通贯穿采用 `SimpleHole2`；沉孔、沉头及锥底盲孔采用
  Hole Wizard 类型化定义。先初始化类型，再写明确的实际尺寸。
- 定位草图坐标转换到全局入口点；面入口以材料内法向判定方向，基准面入口
  根据 `ReverseDirection` 与草图 Z 轴计算，随后用该特征圆柱段检查。
- 选择面时设置 `SetSelectionPoint2`，防止鼠标/投影选择点改变孔位。
- 原生参数缺少可靠肩/尖指示时，以特征阶段圆柱/圆锥测量解析实际深度；无法
  解析则失败。源内置定位草图约束和标准表身份没有完整导出，不能宣称关联无损。

### 4.2 Creo 7

- 沿用 `native -> snapshot/mapping -> write plan -> orchestration`：Toolkit
  元素树采集与纯映射/写计划分离，后者可在无 Toolkit 测试中验证。
- 普通平底采用 Straight；锥底及入口扩大段采用 Custom。填写 Creo 7 完整
  TO/FROM 深度树、终止枚举、方向、尺寸、深度基准、顶面间隙及定位引用。
- 创建和重定义检查 `ProErrorlist`、再生结果和特征 ACTIVE 状态。
- Hole 尺寸设置显式使用 9 位小数精度；仅调用 `ProElementDoubleSet` 会被默认
  精度四舍五入，不能保证肩/尖等价。
- 能映射的 datum point 定位继续解析；不能保留的外部定位引用明确拒绝。
- 面支撑使用 `ProSurfacedata.orient` 将参数曲面的 du×dv 法向还原为实体外法向，
  再确定 TO/FROM；孔位取孔轴与入口平面的交点，不能把原始定位点当实际入口。
- 无关联父平面的固定坐标草图按真实 LocalCSys 创建三点辅助平面；点精度9位，
  构造基线1000模型单位，减少舍入对斜面法向的影响。读侧识别辅助平面并恢复
  固定坐标语义，避免添加伪业务依赖。

### 4.3 NX 11

- 现代 HolePackage 与旧 UFUN 孔分开解析；旧孔按实际参数含义映射，禁止仅按
  API 参数顺序猜测大径/小径、沉孔深/主孔深。
- 写入统一采用现代 General Hole，显式孔形、表达式、DepthOption、方向、减材
  Boolean 和目标实体。平底角使用 0°，不使用 180° 猜测。
- 显式设置 builder/section 容差；入口支撑面指纹使用已测入口点，避免旋转或
  三角面 AABB 中心不在实际平面上。
- 孔加入 read/write/api 几何状态分类，并更新特征映射和面/边缓存，支持后续
  孔引用前一个孔的平底面。
- STEP 214 导出明确 settings 文件与 Windows 规范路径；由 Write API 持有 UF
  会话直到 STEP 导出结束，禁止 UF_terminate 后再尝试初始化会话。Writer 在实际
  保存的 `.prt` 上使用 ExportFromExistingPart/SetInputFile；Reader 使用 Display 模式。

## 5. 回归入口与证据规则

`script/run_hole_regression.ps1` 接受独立原生生成器产生的 JSON 清单；每次运行
新建 `tmp/.../run_<time>_<id>`，目标文件名短且唯一，防止 Creo 同名会话缓存
或旧负例日志影响本次结论。每个正例严格执行：

1. 源原生零件读取，同时导出最终 STEP。
2. `cadexchange_validate` 加载共享模型、检查结构和 XML 特征数量，并确认含 Hole。
3. 目标原生创建，同时导出最终 STEP。
4. 目标回读，再做共享模型校验。
5. XML 孔语义归一化比较及全模型已有语义比较。
6. 独立 `cad_step_compare` 完整双向布尔差集；要求 EQUAL、有效形体和可信布尔。

未启用快速跳过布尔路径。任何必需步骤失败返回非零。负例必须非零失败并含
本次的明确孔能力诊断；CAD 启动/连接失败不能当作预期不支持。

XML 比较先把长度归一到米，再计算实际肩/尖/入口段。只改变肩/尖标注而保持
几何时输出说明；尺寸、位置、方向或贯穿语义改变仍为失败。支撑/定位关联变化
单独警告，已映射的父特征 ID 不产生误报；关联结果不能由几何通过推断。
