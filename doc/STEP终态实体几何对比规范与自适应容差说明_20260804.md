## 一、 概述与设计背景

在跨 CAD 系统（如 SolidWorks、Creo、UG/NX）转换与重构的自动化闭环校验中，**STEP 终态实体对比 (`cad_step_compare`)** 是保障三维几何保真度的最终防线。

在以往使用固定毫米级静态阈值（如绝对体积限死 $0.000001 \text{ mm}^3$、距离限死 $0.01 \text{ mm}$）的实践中，经常在大型工业模型（如体积达 $34.2 \text{ m}^3$ 的构件）上遇到误报：由于各 CAD 几何内核（Parasolid, Pro/ENGINEER, OpenCASCADE）的 NURBS 曲面拟合与表示差异，即使几何形状完全一致，也会产生 $38,612 \text{ mm}^3$ 的绝对体积落差（相对误差仅为 $0.0001\%$）和 $0.0117 \text{ mm}$ 的包围盒偏差，导致固定静态容差判定失败。

为此，`CADExchange` 几何比对引擎全面引入了**基于模型特征尺度（特征对角线长度 $L_{\text{diag}}$ 与基准体积 $V_{\text{ref}}$）的相对自适应动态容差规范**。本文档详细记录 STEP 比对系统的对比项目、判定算法、自适应容差公式及命令行配置规范。

## 二、 比对流程与完整对比项目清单

`cad_step_compare` 采用多层级渐进校验架构，比对项目共包含 6 个核心阶段：

```text
[1] 拓扑与合法性加载 (Input & B-Rep Validity Check)
        ↓
[2] 同域归一化处理 (Same-Domain Normalization Audit)
        ↓
[3] 归一化拓扑 1对1 描述符匹配 (1-to-1 Descriptor Matching)
        ↓
[4] 全局几何与空间指标计算 (Global Metrics Evaluation)
        ↓  (满足条件时可进入 Fast Path)
[5] 布尔实体精细验证 (Boolean Difference Verification)
        ↓
[6] 汇总判定输出 (Compare Status: EQUAL / DIFFERENT / INVALID_INPUT / UNSUPPORTED_SHAPE)
```

### 1. 原始实体合法性校验 (Input & B-Rep Audit)
* **单实体约束 (Solid Count)**：源端与目标端均须包含且仅包含 1 个有效 `TopoDS_Solid`。
* **外壳闭合性 (Shell Closure)**：使用 `BRepTools::IsReallyClosed` 校验 Outer Shell 是否拓扑闭合。
* **B-Rep 几何有效性 (B-Rep Validity)**：使用 `BRepCheck_Analyzer` 验证实体点、线、面无自交、退化或断开。

### 2. 同域归一化处理 (Same-Domain Normalization Audit)
为了消除跨 CAD 导出 STEP 时产生的“缝合冗余边”、“分割曲面”及“半圆柱/半球面切分”，引擎通过 `ShapeUpgrade_UnifySameDomain` 进行拓扑归一化：
* **归一化稳定性校验**：要求归一化后的实体必须保持单实体、闭合、B-Rep 有效，且相对体积漂移小于 $10^{-10}$。
* **拓扑数量统计**：记录面数量变化（$N_{\text{faces, before}} \to N_{\text{faces, after}}$）与边数量变化（$N_{\text{edges, before}} \to N_{\text{edges, after}}$）。
* **曲面/曲线直方图**：分别按 `PLANE`, `CYLINDER`, `CONE`, `SPHERE`, `TORUS`, `BSPLINE` 统计面类型分布；按 `LINE`, `CIRCLE`, `BSPLINE` 统计边类型分布。

### 3. 归一化拓扑 1对1 描述符匹配 (1-to-1 Descriptor Matching)
对归一化后的几何元素抽取几何特征描述符（Descriptor）：
* **面描述符 (`FaceDescriptor`)**：包含面类型 (`typeName`)、表面积 (`areaMm2`)、质心坐标 (`centroidMm`)、包围盒 (`boundsMm`)。
* **边描述符 (`EdgeDescriptor`)**：包含曲线类型 (`typeName`)、曲线长度 (`lengthMm`)、质心坐标 (`centroidMm`)、包围盒 (`boundsMm`)。
* **贪婪 1对1 匹配算法**：在面/边类型一致的前提下，寻找几何距离最近且满足容差阈值的描述符对。记录匹配数（`matchedFaceCount`, `matchedEdgeCount`）与未匹配孤立元素数。

### 4. 全局几何与空间指标 (Global Metrics Audit)
计算实体宏观物理特征与空间定位：
* **体积差异**：绝对体积差 $\Delta V_{\text{abs}} = |V_{\text{ref}} - V_{\text{cand}}|$，相对体积差 $\Delta V_{\text{rel}} = \frac{\Delta V_{\text{abs}}}{\max(V_{\text{ref}}, V_{\text{cand}})}$。
* **质心距离**：$d_{\text{centroid}} = \|\mathbf{C}_{\text{ref}} - \mathbf{C}_{\text{cand}}\|$。
* **包围盒最大落差**：$\Delta B_{\text{max}} = \max\Big(\|\mathbf{P}_{\min,\text{ref}} - \mathbf{P}_{\min,\text{cand}}\|_{\infty},\; \|\mathbf{P}_{\max,\text{ref}} - \mathbf{P}_{\max,\text{cand}}\|_{\infty}\Big)$。

### 5. 布尔实体精细验证 (Boolean Difference Audit)
通过 OpenCASCADE 的 `BOPAlgo_BOP` 算法进行布尔实体求差：
* **丢失材质 (Missing Material)**：$A - B$ 差集实体的总体积（$V_{A-B}$）。
* **新增材质 (Added Material)**：$B - A$ 差集实体的总体积（$V_{B-A}$）。
* **对称差体积 (Symmetric Difference)**：$V_{\text{sym}} = V_{A-B} + V_{B-A}$。
* **内核告警解析**：捕捉 `BOPAlgo_AlertSelfInterferingShape` 等几何自交告警。

## 三、 全局自适应容差规范 (Adaptive Tolerance Standard)

为实现从微毫米级螺钉到数十米级车身构件的全自动无缝比对，所有比对环节均采用**“静态下限 + 特征标度相对比例”**的混合自适应模型：

### 1. 模型特征标度定义 (Characteristic Scale)
定义基准实体包围盒的三维空间对角线长度为模型特征标度 $L_{\text{diag}}$：
$$L_{\text{diag}} = \sqrt{(x_{\max} - x_{\min})^2 + (y_{\max} - y_{\min})^2 + (z_{\max} - z_{\min})^2}$$
*当包围盒无效或 $L_{\text{diag}} \le 0$ 时，默认取 $L_{\text{diag}} = 1.0 \text{ mm}$。*

### 2. 比对阈值与动态自适应公式表

| 比对项目 | 命令行配置参数 | 默认静态下限 (`FloorTol`) | 相对比率 (`RelRatio`) | 动态生效容差计算公式 ($\text{EffectiveTol}$) | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **绝对体积容差** | `--abs-volume-tol-mm3` | `0.001 mm³` | `--rel-volume-tol` (`0.1%`) | $\max\Big(\text{AbsTol},\; \text{RelTol} \times V_{\text{ref}}\Big)$ | 按零件基准体积 0.1% 动态向上扩展 |
| **相对体积容差** | `--rel-volume-tol` | `1.0e-3` (0.1%) | N/A | $\le 0.001$ | 相对体积比门限 |
| **质心与包围盒距离** | `--distance-tol-mm` | `0.02 mm` | `1.0e-4` (0.01%) | $\max\Big(\text{DistanceTolMm},\; 1.0\times 10^{-4} \times L_{\text{diag}}\Big)$ | 允许包围盒对角线长度的 0.01% 落差 |
| **布尔求差模糊容差** | `--boolean-fuzzy-tol-mm` | `0.02 mm` | `1.0e-4` (0.01%) | $\max\Big(\text{FuzzyTolMm},\; 1.0\times 10^{-4} \times L_{\text{diag}}\Big)$ | 确保大尺寸实体求差数学稳定收敛 |
| **归一化缝合线性容差** | `--normalize-linear-tol-mm` | `0.001 mm` | `1.0e-5` (0.001%) | $\max\Big(\text{NormLinearTolMm},\; 1.0\times 10^{-5} \times L_{\text{diag}}\Big)$ | 用于消去面缝合与冗余边合并 |
| **归一化角度容差** | `--normalize-angular-tol-rad`| `1.0e-6 rad` | N/A | `1.0e-6 rad` | 共面法线夹角门限 |
| **面 Descriptor 匹配** | N/A | 面积 `0.01 mm²` | 面积 `1.0e-3` (0.1%) | 面积差 $\le \max(0.01, 10^{-3} A_{\text{ref}})$<br>质心/包围盒 $\le \text{EffectiveDistanceTol}$ | 贪婪 1对1 匹配面条件 |
| **边 Descriptor 匹配** | N/A | 长度 `0.005 mm` | 长度 `1.0e-3` (0.1%) | 长度差 $\le \max(0.005, 10^{-3} L_{\text{ref}})$<br>质心/包围盒 $\le \text{EffectiveDistanceTol}$ | 贪婪 1对1 匹配边条件 |

## 四、 快速路径与最终判定逻辑 (Decision Matrix)

### 1. Normalized Fast Path 快速路径条件
当启用 `--normalized-fast-path`（`-EnableStepFastPath`）时，若同时满足以下三个条件，比对系统将跳过耗时的 $A-B / B-A$ 布尔运算，直接判定为 `EQUAL`：
1. **全局几何指标通过**：`inputVolumePass && centroidPass && boundsPass` 均为真。
2. **拓扑类型直方图一致**：面类型直方图与边类型直方图完全相同。
3. **描述符 1对1 匹配 100%**：所有归一化后的面与边均完成 1对1 描述符匹配（`allFacesMatched && allEdgesMatched`）。

### 2. 判定状态类型 (Compare Status)
* **`EQUAL` (Exit Code 0)**：实体系数在自适应容差内完全相同，或快速路径直接通过。
* **`DIFFERENT` (Exit Code 1)**：布尔对称差体积超标，或全局几何指标超标。
* **`INVALID_INPUT` (Exit Code 2)**：文件缺失、语法解析失败或非合法 STEP 文件。
* **`UNSUPPORTED_SHAPE` (Exit Code 3)**：包含多实体（Multi-solid）或非闭合曲面等不支持类型。
* **`INTERNAL_ERROR` (Exit Code 4)**：OpenCASCADE 内核异常抛出。

## 五、 PowerShell 自动化脚本透传与调用规范

在通用自动化工具链 `script/run_roundtrip_batch.ps1` 和 `script/run_roundtrip.ps1` 中，所有几何容差选项均已完成参数绑定与自动透传：

### 命令行调用示范
```powershell
& .\script\run_roundtrip_batch.ps1 `
    -SourceCad creo `
    -TargetCad sw `
    -InputRoot E:\MyProject\CADparts\Creo `
    -OutputRoot E:\MyProject\tmp\roundtrip_val `
    -EnableStepCompare `
    -EnableStepFastPath `
    -StepRelVolumeTol 1e-3 `
    -StepDistanceTolMm 0.02
```

所有透传参数对应关系说明：
* `-EnableStepCompare`: 启用 STEP 终态比对。
* `-EnableStepFastPath`: 启用归一化拓扑 1对1 匹配快速路径。
* `-StepRelVolumeTol`: 设定相对体积容差（默认 `0.001`）。
* `-StepAbsVolumeTolMm3`: 设定绝对体积容差静态下限（默认 `0.001`）。
* `-StepDistanceTolMm`: 设定质心与包围盒落差静态下限（默认 `0.02`）。
* `-StepBooleanFuzzyTolMm`: 设定布尔求差模糊容差（默认 `0.02`）。
